# The Art of Imperfection

A bespoke, responsive portfolio website for Mel's French-inspired artisan cake studio.

## Brand direction

- French editorial elegance with a rustic, hand-crafted undertone
- Aubergine, sky blue, warm ivory and antique brass palette
- Cormorant Garamond display typography with restrained modern sans-serif copy
- Original AI monogram seal and custom photographic art direction
- Adobe Firefly-generated portfolio photography, reviewed and web-optimised

## Before launch

1. Add Mel's real enquiry address to the `recipient` value in `script.js`.
2. Replace the placeholder Instagram and Pinterest links in `index.html`.
3. Confirm service wording, delivery area and any pricing policy with Mel.
4. Add real client work progressively as photography becomes available.

## Local preview

Open `index.html` directly, or serve the folder with any static web server.

## GitHub Pages

This folder is ready to publish from any GitHub Pages branch. No build step is required.
