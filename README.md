# Aven Prismatic Core Cooler

A lightweight, seamless version of Aven's Prismatic Core wallpaper, reframed for the 480×480 Corsair iCUE TITAN LCD.

## Live page

https://tracedicky.github.io/aven-rgb-singularity-cooler/

The page plays a compact square H.264 loop with no canvas effects, overlays, external assets, or continuous animation scripts.
